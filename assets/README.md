# وضعیت فایل‌های تولیدشده

> ⚠️ **همهٔ این فایل‌ها «پیش‌نمایشِ تأییدنشده» هستند.** هیچ QR واقعی، هیچ نشانی جدید، هیچ نقل‌قول کتاب و هیچ پرتره‌ای در آن‌ها به‌کار نرفته است.

## ۱. تراکت (چاپ)
پوشه: `assets/print/`

| فایل | چیست |
|---|---|
| `generate_card.py` | کد تولید تراکت (قابل تغییر؛ همهٔ متن‌ها و اندازه‌ها در بالای فایل قابل ویرایش‌اند) |
| `preview/side-a.png` | پیش‌نمایش سمت A — «شب / کتابخانه» |
| `preview/side-b.png` | پیش‌نمایش سمت B — «هفت شب» + دروازهٔ QR |
| `preview/preview-both.png` | نمای دوطرفه در کنار هم |
| `print/side-a.pdf` / `side-b.pdf` | PDF با اندازهٔ واقعی A5 (۱۴۸×۲۱۰ mm) + بلید ۳ mm |
| `print/side-a-300dpi.png` | تصویر ۳۰۰dpi |
| `print/side-a-cmyk.tif` | نسخهٔ CMYK (برای چاپخانه) |
| `fonts/` | فونت Vazirmatn (SIL OFL 1.1 — برای چاپ و وب آزاد است) |

** مشخصات فنی اعمال‌شده:** A5، بلید ۳ mm، حاشیهٔ امن ۱۶ mm، ۳۰۰dpi، CMYK/TIFF، فونت پایه ۹–۱۰pt (min 8.5pt برای ریزخط‌ها)، QR جای‌نگهدار ۲۶ mm با فاصلهٔ >۶ mm از متن و > ۱۰ mm از لبهٔ برش.

**جای‌های باز (عمداً خالی):** قاب خط‌چین QR؛ پرترهٔ شما؛ فایل وکتور نشان؛ تأیید تک‌تک جمله‌ها.

## ۲. صفحهٔ دیجیتال (پیش‌نمایش زنده)
پوشه: `assets/web/www/`

| فایل | چیست |
|---|---|
| `index.html` | کل صفحه: قهرمان، پخش‌کنندهٔ صدا، سه لحظهٔ داستان، سه الگو، زنجیرهٔ فعال‌شدن، تأمل، هفت شب، پل به جوما، کارت برند، فوتر حمایتی |
| `media/narration-7min.webm` | نسخهٔ بهینهٔ صدا برای وب (Opus، ۲٫۳ MB) |
| `media/narration-7min.mp3` | نسخهٔ پشتیبان (MP3 مونو، ۳٫۵ MB) |
| `fonts/*.woff2` | فونت نسخهٔ وب |
| `brand/portrait-placeholder.svg` | جای‌نگهدار پرتره |

**منابع بیرونی:** صفر. فونت، تصویر و صدا همه محلی‌اند ⇒ صفحه آفلاین هم کار می‌کند و هیچ داده‌ای جایی فرستاده نمی‌شود.

**«جای لینک»های به‌جامانده:** دکمهٔ «تمرین‌های طرحواره‌درمانی» (غیرفعال است) — تا نشانی مورد تأیید شما نرسد، هیچ لینکی ساخته نمی‌شود.

## ۴. اجرای مجدد
```bash
cd assets/print && python3 generate_card.py     # تراکت
cd assets/web/www && python3 -m http.server 8080 # صفحه
```
