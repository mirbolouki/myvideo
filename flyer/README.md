# تراکت A5 دورو — «کتابخانه نیمه‌شب» | Midnight Library A5 Flyer

تحلیل روان‌شناختی کتاب *کتابخانه نیمه‌شب* — رویداد دکتر جواد میربلوکی
هویت بصری: **Premium Editorial Psychology** — تاریکی (روی A) → روشنایی/کاغذ (روی B)

## وضعیت
- [x] روی A — شب سینمایی، کارت‌های طرحواره، پل به پشت صفحه
- [x] روی B — کاغذ کرم: باکس هدیهٔ تست + فیلدهای نوشتنی، مسیر ۴گام، نشان JOMA با جغد، placeholder کد QR، بلوک اعتماد

## مشخصات فنی چاپ
| آیتم | مقدار |
|---|---|
| اندازه برش (Trim) | 148 × 210 mm (A5 عمودی) |
| Bleed | 3 mm هر طرف → فایل چاپ 154 × 216 mm |
| رزولوشن | 300 DPI (1819 × 2551 px هر رو) |
| رنگ | CMYK — پروفایل خروجی **ISO Coated v2 (FOGRA39)، سقف مرکب 300%** |
| حداکثر TAC اندازه‌گیری‌شده | 289% |
| حاشیه امن | متن بدنه ≥ 10mm از خط برش؛ ریزمتن پا ≥ 9.5mm؛ کادر تزئینی 6mm |
| فایل چاپ | `out/press/midnight_library_A5_flyer_press.pdf` — ۲ صفحه (MediBox = 436.56×612.24 pt) |
| مسترهای CMYK | `out/press/sideA_cmyk_300dpi.tif` و `out/press/sideB_cmyk_300dpi.tif` |
| پروف چاپی | `out/press/proof_sideA.png` و `proof_sideB.png` (خط صورتی=trim، فیروزه‌ای=safe) |

## هویت بصری (هر دو رو)
- رنگ‌ها: `#09131D` سرمه‌ای شب / `#C69E5E` و `#E2BE80` طلایی گرم / `#F0E9DC` کرم کاغذی / `#F3EEE4` کاغذ روی B
- تایپوگرافی: **Vazirmatn v33** (OFL) — وزن‌های Light/Regular/Medium/SemiBold/Bold/Black؛ shaping واقعی فارسی با HarfBuzz + FreeType (رقم فارسی، نیم‌فاصله، لیگاتورها)
- کادر keyline طلایی ۰٫۳۵mm با تورفتگی 6mm در هر دو رو
- لوزی‌های طلایی به‌جای بولت/آیکون آماده؛ خطوط مویی به‌جای جدول
- جغد JOMA: برش ماسک‌شده از `logo.jpg` (هویت دست‌نخورده) — فقط نور/سایه/مقیاس تغییر می‌کند

## مسیر Conversion (بدون ادبیات تبلیغاتی)
داستان → همذات‌پنداری → طرحواره → هدیهٔ تست → تمرین → JOMA
روی A با «ادامهٔ این مسیر، در پشت همین صفحه است» به روی B پل می‌زند.

## ساختار کد
- `typeset.py` — موتور تایپ‌ستینگ فارسی (HarfBuzz shaping، rasterization با FreeType، wrap با حفظ نیم‌فاصله، helperهای گرافیک برداری)
- `side_a.py` / `side_b.py` — چیدمان دو رو با layout solver دومرحله‌ای (توزیع خودکار فضای تنفس)
- `press.py` — تبدیل sRGB→CMYK با LittleCMS + پروفایل eci ISOcoated v2، ساخت PDF چاپ و proof
- `assets/` — آرت سینمایی کتابخانهٔ شب + ماسک جغد

## بازتولید
```bash
/home/user/tools/venv/bin/python side_a.py     # رندر مستر 300dpi
/home/user/tools/venv/bin/python press.py sideA  # CMYK + PDF + proof
```
فونت‌ها: `/home/user/tools/fonts/ttf` (Vazirmatn، از github.com/rastikerdar/vazirmatn)
پروفایل‌ها: `/home/user/tools/icc/` (sRGB v4 + ISOcoated_v2_300_eci)

## چک‌لیست خودارزیابی روی A
1. خوانایی متن‌ها ✔ (کمترین سایز 6.9pt فقط برای ریزمتن پا؛ بدنه 8.1–9pt؛ کارت‌ها 7.2pt)
2. سلسله‌مراتب ✔ (عنوان 33pt → پرسش طلایی 11.5pt → بدنه → کارت‌ها → پا)
3. یکپارچگی دورو ✔ (توکن‌های رنگ/تایپ/کادر مشترک؛ روی B همان سیستم معکوس‌شده روی کاغذ)
4. فضای QR ✔ (مربع 30×30mm سفید با کادر داشبورد داخلی و برچسب «محل قرارگیری کد QR» — بدون کد واقعی، طبق brief)
5. فیلدهای نوشتنی ✔ (دو خط نقطه‌چین با فاصلهٔ ۱۲mm و نقطه‌های ۰٫۳۴mm — مناسب خودکار)
6. Bleed/Safe ✔ (آرت full-bleed؛ متن‌ها داخل safe)
7. عدم نزدیکی عنصر مهم به خط برش ✔ (نزدیک‌ترین: ریزمتن پا 9.7mm)
8. تناسب چاپ A5 ✔ TAC≤289%، K برای مناطق تیره، متن کرم بدون K
9. هویت جغد ✔ (مدالیون ۲۰mm کنار بخش JOMA؛ کراپ ماسک‌شدهٔ یکسان، فقط نور/سایه/مقیاس
10. زیبایی + مکث فکری ✔ (نقطهٔ مکث: کارت‌های طرحواره با زبان اول‌شخص)
